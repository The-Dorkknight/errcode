ErrCode

Source-available · Non-commercial

Turn "something went wrong" into 3-digit codes you can read off a phone camera, say on the phone, or look up on a web page. One line in your Python program ranks the failures, ignores noise like "12% downloading", and packs the whole report, with details, into a short string of digits for a QR code.

The demo window (the plugin is the product): a generated 60,000-line log becomes 13 codes and 168 digits. Screenshot from a Linux sandbox.

One line to plug in

import errcode
errcode.install(app="myprog")

At exit (or on a crash) it prints one footer to stderr, for example:

[errcode plugin_demo] E102 W706 W602  EC2-34739026849376627710778795763564242769252885287944249844
[errcode plugin_demo]   102  ERROR PY.TK_MISSING    Python's Tk GUI toolkit (tkinter) is not installed.
[errcode plugin_demo]   706  WARN  HW.GPU_FALLBACK  No usable GPU - running on the CPU path ...
[errcode plugin_demo]   602  WARN  NET.TIMEOUT      The network operation timed out.

What it does

3-digit codes

Grouped like HTTP codes: 1xx Python, 3xx Windows, 4xx Linux, 8xx embedded and 3D printers, 9xx your own. Quick codes such as E102 W706 fit in a sentence.

Reports as digits

Codes, counts and details (the missing module, the port, the exit code) packed into 20-digit blocks, each with a check digit. A typical report is a 25×25 QR; a 1 MB log came out at 108 digits.

287-entry dictionary

Python, C/C++, Windows, Linux, macOS, network, hardware/GPU, ESP32, STM32, RP2040, Klipper and Marlin failures, each with a plain-language meaning and a suggested fix.

Phone decoder

One offline web page decodes reports, QR parts and quick codes, and has a searchable code book. A QR can link straight to it.

C encoder too

A single header, no heap, so firmware can print the same report on a serial port or a display.

Ranked, noise-free

Worst first: fatal, error, warn, ok. Progress bars, percentages, download speeds and routine INFO lines are ignored; repeats collapse.

Time and date inside

The report carries when it was made (UTC, to the minute), so a scanned QR still says when it happened.

Light on old hardware

Pure Python, no GPU, no Pillow, no numpy. A generated 102,000-line log scanned in about 1.5 s with a peak of about 35 MB in a sandbox test (not on a real Core i3).

Never in your way

No network code. Hooks swallow their own errors. ERRCODE_QUIET=1 silences the footer.

Install and run

Linux / macOS:  ./run.sh
Windows:        double-click run.bat

The launcher makes a private virtual environment, installs the QR dependency (segno) and the package itself, and opens the demo window. Plugin and command line only need Python 3.8+; the demo window also needs tkinter. See the README for per-system hints.
